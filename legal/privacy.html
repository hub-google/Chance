隱私與資料保留說明

版本：2026-11-04。產品上線前公開的資料處理說明，正式營利前仍需完成在地法遵審查。

資料如何儲存

不登入即可使用本機功能。紀錄預設僅存在瀏覽器 localStorage，可由使用者自行刪除、匯出 CSV 或下載 JSON 備份。清除瀏覽器網站資料可能使本機紀錄無法復原。

使用者選擇註冊或登入時，Email 等身分資訊交由 Supabase Auth 處理。只有使用者主動操作上傳，該產品的資料才會寫入 Supabase 私人資料庫。不同產品以代碼隔離，資料庫以登入者身分進行 RLS 驗證。

收集目的及類別

營運分析資料：使用者在各工具內自行輸入的客戶代稱、金額、日期與備註；用於工具計算及雲端備份。問題回報：主題、說明及登入者資訊；用於網站內回覆。試用意願：產品代碼、用途與登入者資訊；用於評估產品需求。系統另記錄雲端寫入時間、操作類型、版次與筆數，不在操作日誌保存原始內容。

保存與刪除

本機資料可由使用者自行刪除或清除網站資料。每一產品的雲端備份可在登入後經兩次確認自行刪除；帳戶、客服及試用申請的完整刪除目前需透過站內客服提出；單一產品的私人附件可於登入後在附件列表逐項刪除；刪除 JSON 備份不會連帶刪除附件。使用者不應認為「登出」即代表資料已刪除。日誌為追查操作所需，刪除政策仍待正式營運前制定。

第三方服務及限制

網站由 GitHub Pages 提供，雲端資料與登入使用 Supabase。佐證檔案保存在 Supabase 非公開 Storage bucket，以登入者身份限制檔案讀取。本專案目前與其他 GitHub Pages 專案共用同一瀏覽器來源網域；正式收集敏感資料前應改用隔離網域及進行安全性檢測。此版不應保存完整支付卡號、身分證號或高度敏感文件。

聯繫方式

註冊登入後，使用各項產品內的「網站內客服與問題回報」提出疑問或個人資料請求。目前未提供 Email 客服收件管道。

此說明不表示已完成正式個資告知義務、資安或法律合規審查。
