# PRD｜接案交付與請款管理

> 版本：v0.1（2026-11-03）｜產品編號：20261020-001｜狀態：已實作瀏覽器單機 MVP，尚未完成正式商業營運部署及付款驗證。

## 1. 產品定位與市場依據

- **目標客戶**：台灣接案者、網頁與設計工作室
- **原始商機**：20261020-001，評分 76，來源 Google 試算表「機會」。
- **來源資料**：https://docs.google.com/spreadsheets/d/103uxu5VmnDj7WBrByD9vjpLgauy8-M6uZXqDSnWk7tI/edit?gid=1377271577
- **實際痛點**：交付與驗收沒有留下完整的請款時間線，容易漏催逾期款項。
- **選題理由**：切入明確且日常高頻的 B2B 收款流程，不依賴銀行 API。
- **定價假設**：NT$299／月（假設）。並非已驗證的付費意願或現有銷售。

## 2. 用戶流程（本次已實作）

1. 打開獨立網址：https://hub-google.github.io/Chance/invoice-proof/
2. 不需登入，新增紀錄，填寫「專案、客戶、里程碑、預定收款、已收款、到期日、驗收狀態」。
3. 儲存後立即計算、顯示狀態與警示，支援搜尋、編輯、刪除。
4. 匯出 CSV、下載完整 JSON 備份、JSON 還原，以及列印／存成 PDF。
5. 資料留在該瀏覽器的 localStorage；非無伺服器多人版本。

## 3. 核心計算與規則

未收款＝里程碑應收－已收款；逾期且未收款則提示

系統提供即時計算與可視化警示，不能把估算值當成平台、銀行或官方核定資料。

## 4. MVP 功能與範圍

**實作範圍**：里程碑管理、收款差額、逾期提醒、客戶憑據摘要、CSV／JSON 匯出；響應式電腦／手機介面、資料輸入驗證、清單搜尋與排序（最新資料優先）、批次 CSV 輸出、JSON 備份與恢復、列印友善檢視。

**未實作**：會員、跨裝置同步、後端資料庫、角色權限、付款扣款／訂閱續費、自動推播通知、外部系統串接、檔案附件存放、收據或正式電子簽署。相關項目不應在行銷上宣稱已具備。

## 5. 資料欄位

| 欄位 | 型態 |
| --- | --- |
| 專案／里程碑 | 文字 |
| 客戶 | 文字 |
| 應收金額（NT$） | 非負數字 |

| 驗收狀態 | 選單：待驗收|已驗收|已取消 |

## 6. 營利模式與驗證

- 定價：NT$299／月（假設），僅根據原始研究的假設。
- 最低驗證：以真實目標客戶訪談至少 10 位；提供現有 MVP 的可用連結；確認至少 3 位願意付費試用，並蒐集節省工時與留存意願。
- 轉成可營利 SaaS 前：加入會員與租戶隔離、資料庫與定期備份、台灣個資與服務條款處理、正式金流、訂閱權限與管理後台、觀測/故障通知。
- 建議推廣渠道：台灣接案者、網頁與設計工作室的相關專業社群、產業協會與示範案例內容；避免把未驗證需求說成已成交。

## 7. 風險與限制

沒有真正的簽核紀錄或附件雲端保存，不能等同法律證明。

- 使用者自行輸入資料，系統不驗證法律、會計、投標、設備或交易事實。
- 本機存放可能因清除網站資料而遺失；跨裝置無法共用；多人使用前必須導入可稽核的後端。
- 一律不在 Git 倉庫保留 API 密鑰、個資或客戶真實交易檔案。

## 8. 驗收標準

1. 使用者可在手機或桌機新增紀錄，重新整理後仍存在（同一瀏覽器、未清除網站資料）。
2. 修改數值會重新計算且 UI 當下更新，異常資料可顯示風險提示。
3. 可搜尋、修改、刪除紀錄；刪除需二次確認。
4. 匯出 CSV 可在試算表開啟；同產品 JSON 備份能在另一瀏覽器環境還原。
5. 不會自動發出或假稱已發出金流、通知、合法文件、官方證明。
6. 個別網址可直接開啟而不依賴首頁導航。

## 10. 已新增的雲端備份與試用申請（2026-11-03）

- **正式網站**：https://hub-google.github.io/Chance/invoice-proof/
- **資料庫**：沿用已連線 Supabase 的獨立 `chance_documents` 與 `chance_trial_requests` 資料表（不動其他專案）。
- **資料隔離**：PostgreSQL RLS 以 `auth.uid()=user_id` 控制所有雲端紀錄，`anon` 無存取權。
- **登入**：支援電子郵件密碼註冊／登入與 Email OTP 登入。首次註冊可能要確認 Email；OTP 需管理員在 Supabase Auth 設定顯示驗證碼的郵件模板。這些外部設定尚未逐項驗證。
- **本機與雲端**：保留原先瀏覽器 localStorage 作為預設儲存。使用者登入後，明確點選「上傳本機紀錄至雲端」或「從雲端下載到本機」，覆蓋前顯示確認，不宣稱自動同步。
- **付費試用**：已可提交意願登記，資料只允許登入本人讀取／新增，防止跨使用者存取。此功能**不是實際收款**；需要有支付服務商、後端金流驗簽、商家帳號、退款流程，才能正式上線收費。
- **驗收**：GitHub Actions 對十個程式與計算邏輯的檢查已通過；已確認獨立網址可公開存取。實際用戶從註冊到雲端寫入、恢復資料仍待端到端操作驗證。
- **安全限制**：十個產品共用 `hub-google.github.io` 網域；正式處理客戶敏感商務資料前，建議使用獨立自有網域與更完整的登入、資料保留政策及安全測試。
