# PRD｜信用卡拒付證據整理器

> 版本：v0.4 工程版（2026-11-04）｜產品編號：20261028-006｜狀態：正式獨立網站已部署；可操作產業功能、雲端私人備份與客服；正式金流及商業驗證仍未完成。

## 1. 產品定位與市場依據

- **目標客戶**：台灣跨境電商及獨立商家
- **原始商機**：20261028-006，評分 80，來源 Google 試算表「機會」。
- **來源資料**：https://docs.google.com/spreadsheets/d/103uxu5VmnDj7WBrByD9vjpLgauy8-M6uZXqDSnWk7tI/edit?gid=1377271577
- **實際痛點**：有交付紀錄但在拒付爭議時找不到正確文件或錯過期限。
- **選題理由**：將拒付案件轉成可檢查的證據清單與提交時間表。
- **定價假設**：NT$2,500／案件（假設）。並非已驗證的付費意願或現有銷售。

## 2. 用戶流程（本次已實作）

1. 打開獨立網址：https://hub-google.github.io/Chance/chargeback-evidence/
2. 不需登入，新增紀錄，填寫「案件、支付商、交易額、理由碼、提交期限、證據完成狀態」。
3. 儲存後立即計算、顯示狀態與警示，支援搜尋、編輯、刪除。
4. 匯出 CSV、下載完整 JSON 備份、JSON 還原，以及列印／存成 PDF。
5. 未登入時留在 localStorage；登入後可手動上傳／下載 Supabase 私人備份，完成初次資料對齊後，可自行開啟版本保護的跨裝置同步；瀏覽器關閉時不會持續同步。
6. 可查看本產業的衍生分析、逐案報告與風險提示，並使用瀏覽器「列印／另存 PDF」。
7. 有固定期限的產品可下載 .ics 行事曆提醒；不會由網站在背景推播。

## 3. 核心計算與規則

證據完成率＝已整理證據項目數÷4；日期提示

系統提供即時計算與可視化警示，不能把估算值當成平台、銀行或官方核定資料。

## 4. MVP 功能與範圍

**實作範圍**：拒付案件時間軸、4類證據完成率、期限警報、可列印清單；響應式電腦／手機介面、資料輸入驗證、清單搜尋與排序（最新資料優先）、批次 CSV 輸出、JSON 備份與恢復、列印友善檢視。

**現階段限制**：已完成 Supabase Auth 登入介面、每人私人雲端備份、RLS、後端審計紀錄、試用意願、客服問題回報及方案資料表。尚未完成**實際金流扣款與自動續訂、付款憑證及退款、多角色共用工作區、附件原檔雲端上傳實測、正式電子簽署、背景推播**。登入寄信、雙帳號隔離及客服真人回覆仍須進行真實使用者端到端驗證。

## 6. 營利模式與驗證

- 定價：NT$2,500／案件（假設），僅根據原始研究的假設。
- 最低驗證：以真實目標客戶訪談至少 10 位；提供現有 MVP 的可用連結；確認至少 3 位願意付費試用，並蒐集節省工時與留存意願。
- 轉成可營利 SaaS 前：加入會員與租戶隔離、資料庫與定期備份、台灣個資與服務條款處理、正式金流、訂閱權限與管理後台、觀測/故障通知。
- 建議推廣渠道：台灣跨境電商及獨立商家的相關專業社群、產業協會與示範案例內容；避免把未驗證需求說成已成交。

## 7. 風險與限制

無文件上傳、無支付商 API；不判定理由碼適法性或保證勝訴。

- 使用者自行輸入資料，系統不驗證法律、會計、投標、設備或交易事實。
- 本機存放可能因清除網站資料而遺失；跨裝置無法共用；多人使用前必須導入可稽核的後端。
- 一律不在 Git 倉庫保留 API 密鑰、個資或客戶真實交易檔案。

## 8. 驗收標準

1. 使用者可在手機或桌機新增紀錄，重新整理後仍存在（同一瀏覽器、未清除網站資料）。
2. 修改數值會重新計算且 UI 當下更新，異常資料可顯示風險提示。
3. 可搜尋、修改、刪除紀錄；刪除需二次確認。
4. 匯出 CSV 可在試算表開啟；同產品 JSON 備份能在另一瀏覽器環境還原。
5. 不會自動發出或假稱已發出金流、通知、合法文件、官方證明。
6. 個別網址可直接開啟而不依賴首頁導航。

## 10. 已新增的雲端備份與試用申請（2026-11-03）

- **正式網站**：https://hub-google.github.io/Chance/chargeback-evidence/
- **資料庫**：沿用已連線 Supabase 的獨立 `chance_documents` 與 `chance_trial_requests` 資料表（不動其他專案）。
- **資料隔離**：PostgreSQL RLS 以 `auth.uid()=user_id` 控制所有雲端紀錄，`anon` 無存取權。
- **登入**：支援電子郵件密碼註冊／登入與 Email OTP 登入。首次註冊可能要確認 Email；OTP 需管理員在 Supabase Auth 設定顯示驗證碼的郵件模板。這些外部設定尚未逐項驗證。
- **本機與雲端**：保留原先瀏覽器 localStorage 作為預設儲存。使用者登入後可手動上傳／下載，覆蓋前須確認；資料對齊後可主動開啟自動同步。同步只在網頁開啟時運作，發生版本衝突則保留本機資料並暫停。
- **付費試用**：已可提交意願登記，資料只允許登入本人讀取／新增，防止跨使用者存取。此功能**不是實際收款**；需要有支付服務商、後端金流驗簽、商家帳號、退款流程，才能正式上線收費。
- **驗收**：GitHub Actions 對十個程式與計算邏輯的檢查已通過；已確認獨立網址可公開存取。實際用戶從註冊到雲端寫入、恢復資料仍待端到端操作驗證。
- **安全限制**：十個產品共用 `hub-google.github.io` 網域；正式處理客戶敏感商務資料前，建議使用獨立自有網域與更完整的登入、資料保留政策及安全測試。


## 11. CSV 批次資料導入（2026-11-03 追加）

- **限制**：尚未串接外部付款與官方 API、私人 PDF/JPG/PNG 佐證附件已加入，尚未經真人正式環境端到端驗證；無正式數位簽署；本產品不得宣稱這些已完成。

## 13. 安全跨裝置同步與雲端刪除（2026-11-04）

- 預設不啟用自動同步，必須先手動上傳／下載一次，確認本機與雲端資料一致才可開啟。
- 同步採伺服器文件版本號進行樂觀鎖檢查（`PATCH ... version=eq.N`）。當其他裝置先更新、版本不同時，舊裝置立即停止寫入，不覆蓋本機資料。
- 當網頁開啟時，編輯後短暫等待上傳；每 25 秒檢查雲端較新版本並在安全時讀取。關閉頁面後**沒有持續執行的背景通知或資料同步**。
- 使用者可經兩次確認刪除**本產品**在雲端的私人備份，其他產品與本機資料均不受影響；後端操作記錄仍保留。
- 支援網站內客服問題、回覆與處理狀態；付費方案只顯示伺服器核定的訂閱紀錄，禁止使用者自行宣稱已付款。
- 驗收證據：Playwright 已在隔離的模擬 REST 環境測試雲端上傳、版本加一的自動同步、站內客服、回覆讀取及刪除；**尚未以真實帳號完成生產環境端到端登入與付款**。

## 14. 私人佐證附件、營運後台與 PRD 商業化驗收（2026-11-04）

- **附件**：已建立 Supabase 私人 bucket `chance-evidence`，限制 JPG／PNG／PDF，單檔最多 5 MiB；檔案路徑依登入者 user ID + 產品代碼 + 紀錄 ID 隔離，Storage 與附件索引均採 RLS。
- **附件 UI**：選取紀錄後可上傳、查看清單、授權下載、單檔刪除。附件不會因刪除 JSON 雲端備份自動清除；可獨立刪除。
- **站內客服營運後台**：已建立 `/Chance/admin/`，供後端核實加入 `chance_admins` 名單的管理員查看客服問題、回覆、更新狀態及查詢試用意願。一般使用者沒有存取他人紀錄的權限。
- **管理員開通限制**：尚未為任何人自動授權管理員，需先核實 Supabase Auth user ID，再於受保護後端明確加入名單。避免以公開 Email、客戶端參數或假測試帳號自動取得權限。
- **付款與訂閱**：`chance_billing_plans`（10 筆價格假設，`checkout_enabled=false`）、`chance_billing_orders`、`chance_entitlements` 已建立；瀏覽器只允許經 RLS 讀取自有訂單及訂閱，不得直接寫入成功付款或解鎖付費。
- **測試**：十項產品的 CRUD／報告／A4 列印已使用 Chromium 測試；雲端同步與客服使用合成 REST 模擬測試。真人登入、附件實際上傳下載、管理員上線及金流付款**尚未具備正式環境完整驗收證據**。
- **正式上線條件**：金流商家資格、商店授權憑證、交易建立與 server-side webhook 驗簽、對帳／退款／發票、法遵審查、自有網域與會員刪除流程、真實付費客戶試點。此前價格頁與申請表不等於正式收費。
